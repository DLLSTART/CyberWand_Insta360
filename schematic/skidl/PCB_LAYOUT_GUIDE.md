# CyberWand v2.3 - PCB布局与焊盘连接指南

> **板尺寸**: 100mm × 85mm | **层数**: 4层  
> **层叠**: F.Cu(信号) / In1(GND平面) / In2(3V3平面) / B.Cu(信号)

---

## 一、4层板层叠结构

```
  ┌─────────────────────────────────────────┐
  │ ████████████████████████████████████████ │ ← F.Cu (正面铜层)
  │ 正面元件 + 信号走线                      │    元件焊盘、信号走线
  ├─────────────────────────────────────────┤
  │ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │ ← In1.Cu (GND完整平面)
  │ 整面铺铜接GND, 缝合Via连接正反面GND      │    EMI屏蔽 + 信号回流
  ├─────────────────────────────────────────┤
  │ ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ │ ← In2.Cu (3V3电源平面)
  │ 整面铺铜接3V3, 低阻抗电源分配           │    电源完整性
  ├─────────────────────────────────────────┤
  │ ████████████████████████████████████████ │ ← B.Cu (背面铜层)
  │ 背面元件(电池/扬声器) + 溢出走线          │    GND铺铜填充
  └─────────────────────────────────────────┘

  板厚: 1.6mm (标准)
  铜厚: 外层35μm, 内层17.5μm
  Via:  0.5mm外径 / 0.25mm钻孔 (通孔)
```

## 四、PCB关键走线路径示意

### 4.1 电源走线 (加粗, ≥0.3mm)

```
  J2(USB)                    正面F.Cu层
  VBUS ═══[F1 PTC]═══ 5V_PROT ═══╤═══ U4.Pin4(VCC)
                               ║  ╠═══ U6.Pin5(ESD VBUS)
                               ║  ╠═══ U7.Pin14(74AHCT VCC)
                               ║  ╠═══ D1/D2/D3.Pin1(VDD)
                               ║  ╠═══ R11/R12.Pin1(LED限流)
                               ║  ╚═══ C15/C17(滤波到GND)
                               ║
  U4.Pin5(BAT) ═══ VBAT ═══╤═══ BT1(+)
                            ╠═══ SW1.Pin1(COM)
                            ╚═══ C_BAT(去耦到GND)
                               ║
  SW1.Pin2(NO) ═══ VBAT_SW ═╤═══ U5.Pin1(VIN)
                             ╚═══ C14(去耦到GND)
                               ║
  U5.Pin2(VOUT) ═══ 3V3 ═══╤═══ U1.Pin2(ESP32 VDD)
                            ╠═══ U2.Pin13(MPU VDD)
                            ╠═══ LCD1.Pin2/Pin8(VCC/BLK)
                            ╠═══ J1.Pin4(SD VCC)
                            ╠═══ U3.Pin1(DFPlayer VCC)
                            ╠═══ MIC1.Pin1(INMP VDD)
                            ╠═══ 所有上拉电阻端
                            ╚═══ C9/C1~C10(去耦到GND)

  GND ← 通过Via连接In1.Cu整面GND平面
  3V3 ← 通过Via连接In2.Cu整面3V3平面
```

### 4.2 SPI总线走线 (信号, 0.2mm)

```
  U1(ESP32)                        LCD1               J1(SD)
  Pin17(IO9)──[R13 33Ω]──SPI_SCK──┤Pin3(SCL)  ┌──Pin5(SCK)
  Pin21(IO13)─[R14 33Ω]──SPI_MOSI─┤Pin4(SDA)  ├──Pin7(MOSI)
  Pin20(IO12)─────────────SPI_MISO─┤           ├──Pin8(MISO)
  Pin22(IO14)─────────────CS_LCD───┤Pin7(CS)   │
  Pin18(IO10)─────────────CS_SD────┤           └──Pin2(CS)
  Pin19(IO11)─────────────LCD_DC───┤Pin6(DC)
  Pin10(IO17)─────────────LCD_RST──┤Pin5(RES)

  ★ SCK/MOSI经33Ω阻尼后分叉到LCD和SD
  ★ 走线尽量等长, 避免跨越ESP32天线区域
```

### 4.3 I2C走线

```
  U1(ESP32)                    U2(MPU6050)
  Pin4(IO4) ────── I2C_SDA ─── Pin24(SDA)
                       │
                   [R2 4.7K]

  Pin5(IO5) ────── I2C_SCL ─── Pin23(SCL)
                       │
                   [R3 4.7K]
                       │

```

### 4.4 USB差分对走线 (★等长+平行)

```
  J2(Type-C)            ESD(U6)              U1(ESP32)
  DP1/DP2 ──[R18 22Ω]──Pin1,6(IO1)─── Pin14(IO20)
  DN1/DN2 ──[R19 22Ω]──Pin3,4(IO2)─── Pin13(IO19)

  ★ D+/D-必须:
    - 走线等长 (误差<0.1mm)
    - 平行走线, 恒定间距
    - 差分阻抗90Ω
    - 避免过Via换层
```

```
  │ ○     ○     ○     ○     ○     ○     ○     ○     ○    ○ │ ← 底边每8mm
  └──────────────────────────────────────────────────────────┘

  ○ = GND Via (0.5mm外径/0.25mm钻孔)
  作用: 连接F.Cu和B.Cu的GND到In1.Cu GND平面
```

## 七、关键布局规则

```
1. ESP32天线净空区 (模块短边15mm范围):
   ┌─────────────────┐
   │ ░░░ 禁止区域 ░░░│ ← 无铜箔
   │ ░░ 无元件/走线 ░░│ ← 无元件
   │ ░░░░░░░░░░░░░░░ │ ← 无Via
   ├─────────────────┤
   │  ESP32模块本体   │
   └─────────────────┘

2. 去耦电容放置:
   ┌──IC──┐
   │ VCC●─┤─── 3V3
   │      │ ■ ← 100nF紧贴VCC引脚(≤3mm)
   │ GND●─┤─── GND
   └──────┘

3. TP4056散热:
   VCC(Pin4)和GND(Pin3)焊盘做大铜皮
   连接Via到内层GND平面散热

4. USB差分对:
   DP ═══════════════  间距恒定(通常0.15mm)
   DN ═══════════════  走线等长
```
