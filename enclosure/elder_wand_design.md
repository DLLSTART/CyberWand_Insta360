## 二、人手比例锚定

参考成年男性手部尺寸：
- 手心抓握长度: **~95 mm** → 手柄长度匹配 95 mm（z=14..104）
- 拇指厚度（横向参考）: ~22 mm → 杖身手柄 Φ34（贴近手感上限，受电池宽度约束，已经是最小可行）
- 中指端到端的相对位置告诉我们雕花结应在指尖刚好接触的位置：z ≈ 110~155
- 螺旋杖身 + 锥尖共占 ~210 mm 视觉延伸

## 四、电子腔布置（v4 核心创新）

### 4.1 PCB + 电池"竖向叠放"

PCB 与电池**沿杖轴方向端到端叠放**，不再横向铺开。这是 v4 杖身能瘦身的关键。

```
   z=98 ──────────────  ← 腔顶（接走线通道 → 杖尖）
   ┌──────────┐
   │ ESP32-S3 │ z=62..97（35 mm）
   │ PCB      │ 竖立放置：宽 25 mm 沿 X，厚 1.6 mm 沿 Y
   └──────────┘
   z=58 ── 间隔 4 mm（连接器 / 排线 / 焊点）
   ┌──────────┐
   │ 锂电      │ z=18..58（40 mm）
   │ 603040   │ 竖立放置：宽 30 mm 沿 X，厚 6 mm 沿 Y
   └──────────┘
   z=16 ──────────────  ← 腔底（pommel 螺孔上方）
```

### 4.2 配重原则（重点）

**重电池靠近 pommel 端**（手腕侧），轻 PCB 靠近指尖侧。  
理由：成年男性握杖时，手腕承担最大支点力矩；将 ~8 g 电池放在握点附近，能减少手腕扭矩感，让杖身使用时**重心落在手心**而非"前重头沉"，挥动时手感更接近木质魔杖。

### 4.3 关键尺寸 ＆ 间距

| 元素 | 尺寸 | 位置 | 余量 |
|---|---|---|---|
| Cavity 圆柱内径 | Φ31 mm | z=16..98 | 电池 30×6 截面对角 30.6 → 0.4 mm 间隙 |
| Cavity 长度 | 82 mm | | PCB 35 + 间隙 4 + 电池 40 = 79 mm + 3 mm 余量 |
| 手柄壁厚 | 1.5 mm | （Φ34 - Φ31）/2 | 4 周线 0.4 喷嘴可打 |
| Pommel 旋盖螺孔 | M6 × 6 mm 深 | z=0..6 | 自攻丝或一次成型外螺纹 |

### 4.4 外部接口位置

| 接口 | z 位置 | 朝向 | 尺寸 |
|---|---|---|---|
| **USB-C** | 70 (PCB 下端) | +X 侧 | 9 × 4 mm |
| **用户按键** | 80 (PCB 中段) | +Y 侧 | Φ4 |
| **状态 LED 窗** | 90 (PCB 上段) | -X 侧 | Φ2.2 |
| **电源开关** | 22 (电池下方) | -Y 侧 | 6 × 3 mm |
| **走线通道** | 98 → 355（杖尖前 5 mm） | 同轴 | Φ2.5 |

## 五、螺旋藤蔓雕刻算法（v4.1 单股自然螺旋）

### 5.1 实现方式

使用 OpenSCAD 的 `linear_extrude` + `twist` + `scale` 三参数组合，在一个含**单凸点 + 切向拉长椭圆**的 2D 截面上做扭转拉伸，得到接近天然木藤的"扁枝"缠绕感。

```scad
linear_extrude(height = 170, twist = 2.2 × 360, scale = 4/16, slices = 240)
    union() {
        circle(r = 8 - 0.05);                          // 中心核
        translate([8 - 2.0 × 0.25, 0, 0])
            scale([1, 1.6, 1])                          // 切向拉长 1.6 倍
                circle(r = 2.0);                       // 单股藤蔓凸点
    }
```

### 5.2 视觉参数

| 参数 | 取值 | 美学作用 |
|---|---|---|
| `spiral_turns` | **2.2** | 单股需要更多圈数才有"缠绕感" |
| `spiral_vines` | **1**（单股） | 接近天然木藤，不规则、有方向性 |
| `vine_height` | **2.0 mm** | 加粗补偿单股缺失，藤蔓凸起明显 |
| `vine_width_k` | **1.6** | 切向拉长系数，藤蔓断面像"扁枝"非"圆球" |
| 锥度 | r_tip / r_root = 4/16 = 0.25 | 包络从 Φ16 → Φ4 |

### 5.3 与上手图的区别

参考图为天然木质单股螺旋，v4.1 还原 ——
- ✓ 单股螺旋，2.2 圈缠绕，接近自然木藤
- ✓ 切向椭圆截面，藤蔓像"扁枝"而不是"圆球做螺旋"
- 折中：仍是几何对称的螺旋（无随机不规则感），FDM 打印需 30° 内悬空可免支撑

## 七、雕花结（v4.2 光滑水钻簇·无尖角安全版）

> v4.1 曾用 4 棱锥金字塔做"碎冰锐角"，但锐尖可能划伤手部 / 衣物 / 收纳袋，
> v4.2 改为光滑圆顶 cabochon（半埋圆球），保留密集水钻簇视觉但表面圆润安全。

### 7.1 三环带 24 颗光滑 cabochon

```
  band 上方逐渐鼓起到 Φ28 椭球，z=129..151
  
  ───── 上环：6 颗光滑圆顶，仰 35° ─────
   ●    ●    ●    ●    ●    ●        bump_r=1.4, 凸出 0.9 mm
  ════════════════════════════
  ●  ●  ●  ●  ●  ●  ●  ●  ●  ●  ●  ●   赤道：12 颗大圆顶（主簇面）
  ════════════════════════════                 bump_r=1.6, 凸出 1.1 mm
   ●    ●    ●    ●    ●    ●        
  ───── 下环：6 颗光滑圆顶，俯 35° ─────
  
  上下两道 Φ0.6 × 0.6 mm 领圈凹环（雕花结收口）
```

### 7.2 光滑 cabochon 几何

每颗水钻为 `sphere(r=bump_r, $fn=32)`（高 $fn 保证表面光滑），
半埋在雕花结表面（圆心嵌入 0.5 mm），仅露出 ~70% 的圆球，
形成**镶嵌的水钻 / 抛光珍珠**视觉效果。

**安全属性**：
- 凸起最高 1.1 mm，圆顶曲率 R≈1.6 mm（接触面积大）
- 触感：类似手机按键 / 蓝牙耳机的物理按键
- 即使刮擦也只产生压痕，不会划伤皮肤 / 织物

### 7.3 摆放算法

```scad
// 球面坐标 (φ azimuth, θ altitude) 投射到 X-Y-Z
rotate([0, 0, phi])              // 方位角
    rotate([0, -theta, 0])       // 仰角（+ 向上 / − 向下）
        translate([anchor_r, 0, 0])
            rotate([0, 90, 0])
                cylinder(h, r1, r2, $fn = 4);
```

3 环带分别用 phi 错相 + 不同 anchor_r + 不同凸起高度：
| 环带 | 数量 | 仰角 θ | 错相 | bump_r | anchor_r | 凸出 |
|---|---|---|---|---|---|---|
| 赤道 | 12 颗 | 0° | 0° | 1.6 | r_knot − 0.5 | 1.1 mm |
| 上环 | 6 颗 | +35° | 15° | 1.4 | r_knot − 1.4 | 0.9 mm |
| 下环 | 6 颗 | −35° | 15° | 1.4 | r_knot − 1.4 | 0.9 mm |

总共 **24 颗**，相邻 30° 间距（赤道）/ 60° 间距（上下环），构成密集圆顶水钻簇。

### 7.4 后期可选精修

参考图中是一颗带"小脸 / 古卢恩字符"浮雕的小球。v4.1 几何已经接近，  
若想做更细节，打印后可用：
1. 微型雕刻刀手雕（在 4 棱台之间凹处加细纹路）
2. CNC 数控雕刻（直接在 4 棱台顶面刻入卢恩文字）
3. 3D 笔（fdm 极细线）补刻人脸侧影

## 九、后处理 / 上色（强烈建议）

要让上手图的"葡萄藤雕花·岁月木质"质感真正落地：

1. **打磨**：320# → 600# → 1200# 砂纸顺纹路打磨，去除所有 layer line
2. **底色**：**深胡桃木色木蜡油**（建议自然木丝 PLA + 木蜡油渗透，不喷漆）
3. **铜环上色**：铜环（z=104~111）单独遮蔽喷"古铜金"哑光漆，干涂法保留质感
4. **Pommel 上色**：单独喷古铜金，与铜环统一
5. **螺旋藤蔓干刷**：用浅黄褐色干刷藤蔓凸起的棱线，使藤蔓"亮"于核心
6. **雕花结**：在 6 颗赤道凸点中心点入暗红宝石漆，模拟红玉镶嵌
7. **罩光**：哑光透明罩光漆 + 蜡，保护 + 防汗
