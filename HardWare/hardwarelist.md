## 项目概述
- 项目名称：赛博魔杖（CyberWand）
- 主控平台：ESP32-S3-WROOM-1N16R8
- 开发平台：KiCad 9.0 + SKiDL
- 产品尺寸：宽60-70mm，长120-150mm

## 电源系统设计

### 电源拓扑（实际电路）
```
USB Type-C (5V)
    ↓
    ├─ VBUS → 10μF滤波电容 → TP4056 VIN
    ├─ CC1 → 5.1KΩ → GND (Sink模式配置)
    ├─ CC2 → 5.1KΩ → GND (Sink模式配置)
    ├─ D+ → (ESD保护) → ESP32-S3 (预留)
    ├─ D- → (ESD保护) → ESP32-S3 (预留)
    └─ GND → 系统地
    
TP4056 (充电管理)
    ├─ VIN ← USB Type-C VBUS (5V)
    ├─ BAT → 锂电池+ (充电输出)
    ├─ PROG → 2KΩ → GND (设置500mA充电电流)
    ├─ CE → 3.3V (充电使能，高电平有效)
    ├─ RST → 3.3V (复位，高电平有效)
    ├─ CHRG → 1KΩ → LED红(阳极) → LED红(阴极) → GND (充电指示)
    ├─ STDBY → 1KΩ → LED绿(阳极) → LED绿(阴极) → GND (充满指示)
    └─ GND → 系统地
    
603040锂电池 (800mAh)
    ├─ + → TP4056 BAT & ME6211 VIN
    └─ - → 系统地
    
ME6211 (3.3V LDO)
    ├─ VIN ← 锂电池+ (3.7V)
    ├─ VIN → 10μF输入电容 → GND
    ├─ VOUT → 10μF输出电容 → GND
    ├─ VOUT (3.3V) → 所有3.3V外设
    │   ├─ ESP32-S3 (主控)
    │   ├─ MPU6050 (传感器)
    │   ├─ ST7789 LCD (显示)
    │   ├─ MicroSD (存储)
    │   ├─ DFPlayer (音频)
    │   ├─ INMP441 (麦克风)
    │   └─ 按键上拉电阻
    └─ GND → 系统地

WS2812B LED x3 (RGB指示灯)
    ├─ VDD ← USB Type-C VBUS (5V，更高亮度)
    ├─ DIN ← ESP32-S3 IO21 (第一个LED)
    ├─ DOUT → DIN (串联到第二个LED)
    └─ GND → 系统地
```

### Type-C充电电路设计
```
USB Type-C母座
    ├─ VBUS (A4/B4) → 10μF滤波电容 → TP4056 VIN
    ├─ CC1 (A5) → 5.1KΩ电阻 → GND
    ├─ CC2 (B5) → 5.1KΩ电阻 → GND
    ├─ D+ (A6/B6) → ESD保护 → ESP32-S3 D+
    ├─ D- (A7/B7) → ESD保护 → ESP32-S3 D-
    └─ GND → 系统地
```

## PCB设计建议

### 尺寸规划
- PCB尺寸：60mm x 130mm（符合魔杖尺寸要求）
- 板厚：1.6mm
- 层数：2层或4层（建议4层以优化EMI）

### 布局建议
1. ESP32-S3放置在PCB中心位置
2. USB Type-C接口放置在PCB一端，便于充电和数据传输
3. LCD显示屏放置在PCB顶部
4. 按键放置在便于操作的位置
5. 电池仓设计在PCB背面
6. MicroSD卡座放置在PCB边缘，便于插拔
7. 天线区域保持净空，避免金属遮挡
8. Type-C接口附近预留足够空间，避免与按键和LED冲突

### Type-C接口PCB设计要点
1. Type-C母座放置在PCB边缘，便于插拔
2. VBUS走线加宽，至少0.3mm，承载3A电流
3. D+/D-差分走线，保持等长和等距，阻抗控制90Ω
4. CC引脚走线尽量短，靠近Type-C接口
5. 在VBUS和GND之间放置滤波电容
6. Type-C金属外壳通过多个过孔连接到地平面
7. Type-C接口周围保持净空，避免干扰

### EMC/EMI设计
1. 电源输入端添加π型滤波
2. 每个IC电源引脚添加去耦电容
3. 高速信号线（SPI、I2S）做阻抗匹配
4. 蓝牙/WiFi天线区域做好屏蔽
5. USB数据线添加ESD保护
6. Type-C接口周围做好地线包围

## 注意事项
1. ESP32-S3需要考虑天线设计，建议使用板载天线或外接天线
2. MPU6050安装位置应靠近PCB中心，减少振动干扰
3. LCD显示屏需要考虑视角和背光控制
4. 电池仓需要考虑散热和安全防护
5. 语音模块需要考虑音频输出质量
6. 整体设计需要考虑防水防尘（至少IP54级别）
7. MicroSD卡座需要考虑防尘设计，避免灰尘进入
8. MicroSD卡建议使用Class 10以上速度等级，保证数据读写性能
9. Type-C接口需要选择带金属外壳的型号，提高机械强度
10. Type-C接口的CC引脚必须配置5.1KΩ下拉电阻，否则无法正常识别
11. USB数据线必须添加ESD保护，防止静电损坏
12. Type-C接口的VBUS走线要足够宽，确保能承载充电电流
13. Type-C接口周围要做好EMI防护，避免干扰其他电路
