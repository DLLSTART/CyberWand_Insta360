## 电源系统设计

### 电源拓扑
```
USB Type-C (5V)
    ↓
TP4056 (充电管理)
    ↓
锂电池 (3.7V)
    ↓
ME6211 (3.3V LDO) → ESP32-S3主控
    ↓
XC6206 (3.3V LDO) → MPU6050、LCD、存储等外设
```

### 功耗估算
| 模块 | 工作电流 | 待机电流 |
|------|----------|----------|
| ESP32-S3 | ~150mA | ~10mA |
| MPU6050 | ~3.8mA | ~0.5mA |
| LCD | ~20mA | ~0.1mA |
| WS2812B LED | ~60mA | ~0mA |
| DFPlayer Mini | ~30mA | ~1mA |
| INMP441 | ~1.4mA | ~10μA |
| W25Q64 | ~5mA | ~1μA |
| **总计** | **~270mA** | **~12mA** |

### 电池续航估算
- 工作时间：800mAh / 270mA ≈ 3小时
- 待机时间：800mAh / 12mA ≈ 67小时

## PCB设计建议

### 尺寸规划
- PCB尺寸：60mm x 130mm（符合魔杖尺寸要求）
- 板厚：1.6mm
- 层数：2层或4层（建议4层以优化EMI）

### 布局建议
1. ESP32-S3放置在PCB中心位置
2. USB接口放置在PCB一端
3. LCD显示屏放置在PCB顶部
4. 按键放置在便于操作的位置
5. 电池仓设计在PCB背面
6. 天线区域保持净空，避免金属遮挡

### EMC/EMI设计
1. 电源输入端添加π型滤波
2. 每个IC电源引脚添加去耦电容
3. 高速信号线（SPI、I2S）做阻抗匹配
4. 蓝牙/WiFi天线区域做好屏蔽

## 注意事项
1. ESP32-S3需要考虑天线设计，建议使用板载天线或外接天线
2. MPU6050安装位置应靠近PCB中心，减少振动干扰
3. LCD显示屏需要考虑视角和背光控制
4. 电池仓需要考虑散热和安全防护
5. 语音模块需要考虑音频输出质量
6. 整体设计需要考虑防水防尘（至少IP54级别）
