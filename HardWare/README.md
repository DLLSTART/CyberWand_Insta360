## 🔌 核心器件选型

### 1. 主控芯片 - ESP32-S3
| 参数 | 规格 |
|------|------|
| **型号** | ESP32-S3-WROOM-1 |
| **CPU** | Dual-core Xtensa LX7, 240MHz |
| **Flash** | 8MB PSRAM |
| **无线** | WiFi 4 (802.11 b/g/n) + BLE 5.3 |
| **GPIO** | 45 个可编程 GPIO |
| **封装** | LGA 38-pin |
| **供应商** | 乐鑫 (Espressif) |
| **单价** | ¥25 (1k+) |

**选型理由**:
- 集成 WiFi+BLE，无需外置射频
- 低功耗，支持 Deep Sleep 模式
- 开发生态完善（ESP-IDF）
- 国产芯片，供货稳定

---

### 2. 姿态传感器 - MPU6050
| 参数 | 规格 |
|------|------|
| **型号** | MPU-6050 |
| **类型** | 6 轴 IMU（3 轴加速度 +3 轴陀螺仪） |
| **接口** | I2C（最高 400kHz） |
| **量程** | ±2g/±4g/±8g/±16g, ±250/±500/±1000/±2000°/s |
| **封装** | QFN 16-pin (4×4mm) |
| **供应商** | InvenSense (TDK) |
| **单价** | ¥8 (1k+) |

**选型理由**:
- 经典 6 轴 IMU，资料丰富
- I2C 接口，布线简单
- 功耗低，适合电池供电
- 成本低，性价比高

## 🔌 硬件连接

### 电源部分
```
Type-C (5V) ──┬── TP4050 ──┬── 电池 (3.7V)
              │            │
              │            └── XC6206 ── 3.3V ──┬── ESP32-S3
              │                                 └── MPU6050
              └── 5V ────────────────────────────┴── WS2812B
```

### ESP32-S3 引脚分配
| GPIO | 功能 | 连接 | 说明 |
|------|------|------|------|
| GPIO10 | I2C_SDA | MPU6050_SDA | 传感器数据 |
| GPIO11 | I2C_SCL | MPU6050_SCL | 传感器时钟 |
| GPIO12 | BUTTON | 轻触开关 | 用户输入 |
| GPIO13 | LED_DATA | WS2812B_DI | RGB 灯控制 |
| GPIO14 | BAT_ADC | 电池电压检测 | ADC 输入 |
| GPIO15 | CHG_STAT | TP4050 充电状态 | 输入 |

### MPU6050 连接
| MPU6050 引脚 | ESP32-S3 引脚 | 说明 |
|-------------|---------------|------|
| VCC | 3.3V | 电源 |
| GND | GND | 地 |
| SDA | GPIO10 | I2C 数据 |
| SCL | GPIO11 | I2C 时钟 |
| INT | - | 中断（未使用） |
| AD0 | GND | I2C 地址 0x68 |

## 📐 PCB 设计

### 板框尺寸
- **外形**: Φ14mm 圆柱（适配魔杖外壳）
- **厚度**: 1.6mm
- **层数**: 2 层
- **工艺**: 沉金（便于小间距焊接）

### 布局要点
1. **ESP32-S3 居中** - 射频天线净空区
2. **电池连接器** - 靠近边缘，便于走线
3. **Type-C 接口** - 露出外壳，便于充电
4. **MPU6050** - 远离电源，减少干扰

### 布线要点
1. **射频天线** - 下方禁止铺铜
2. **电源走线** - 加宽（≥ 0.5mm）
3. **差分对** - 等长等距（USB D+/D-）
4. **地平面** - 完整，减少 EMI
