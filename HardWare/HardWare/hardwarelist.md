## 电源系统设计 (v2.0)
```
USB Type-C (5V)
    ↓
    ├─ VBUS (5V) → [PTC保险丝 500mA] → 5V_PROT (保护后5V)
    │   ├─ → 10μF + 22μF 滤波/储能电容
    │   ├─ → USBLC6-2SC6 ESD保护 VBUS引脚
    │   ├─ → TP4056 VIN (充电管理)
    │   ├─ → SN74AHCT125 VCC (5V电平转换器)
    │   └─ → WS2812B VDD x3 (RGB LED)
    ├─ D+ → 22Ω → USBLC6 IO1 → ESP32 (ESD保护+阻抗匹配)
    ├─ D- → 22Ω → USBLC6 IO2 → ESP32
    ├─ CC1 → 5.1KΩ → GND (Sink配置)
    ├─ CC2 → 5.1KΩ → GND
    └─ GND → 系统地

TP4056 (充电管理)
    ├─ VIN ← 5V_PROT
    ├─ BAT → VBAT (电池电压)
    ├─ CHRG → 1KΩ → LED红 → GND (充电中)
    ├─ STDBY → 1KΩ → LED绿 → GND (充满)
    └─ PROG → 2KΩ → GND (500mA)

锂电池 (3.7V/800mAh)
    ├─ + → VBAT
    └─ - → GND

[电源总开关 MSK-12C02]
    ├─ COM ← VBAT (电池)
    └─ NO → VBAT_SW (开关后电池电压)

ME6211 (3.3V LDO)
    ├─ VIN ← VBAT_SW
    ├─ VOUT → 3V3 (所有3.3V外设)
    └─ 输入10μF + 输出10μF 去耦
```
