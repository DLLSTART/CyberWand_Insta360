### 2.2 MPU6050 传感器详细规格

```
MPU6050 技术参数:
├── 加速度计：±2/±4/±8/±16g (可编程)
├── 陀螺仪：±250/±500/±1000/±2000°/s (可编程)
├── 通信接口：I2C (最高 400kHz)
├── 工作电压：2.375V - 3.46V (兼容 3.3V)
├── 封装尺寸：4×4×0.9mm (QFN)
└── 工作电流：3.9mA (典型)

ESP32-C6 连接:
├── VCC → 3.3V
├── GND → GND
├── SCL → GPIO 7 (I2C 时钟)
├── SDA → GPIO 6 (I2C 数据)
└── INT → GPIO 5 (中断，可选)
```

### 2.3 引脚分配表

| ESP32-C6 引脚 | 功能 | 连接设备 | 说明 |
|--------------|------|----------|------|
| **GPIO 18/19** | USB_UART | USB Type-C | 默认 USB 串口 |
| **GPIO 6** | I2C_SDA | MPU6050 | IMU 数据 |
| **GPIO 7** | I2C_SCL | MPU6050 | IMU 时钟 |
| **GPIO 5** | I2C_INT | MPU6050 | 中断 (可选) |
| **GPIO 4** | BUTTON | 物理按键 | 模式切换 |
| **GPIO 3** | LED | LED 指示灯 | 灯语指示 |
| **GPIO 8/9** | RF_ANT | 板载天线 | 蓝牙/WiFi |

## 三、电路设计

### 3.1 MPU6050 接口电路

```
ESP32-C6                    MPU6050
────────                    ───────
3.3V      ──────────────▶   VCC
GND       ──────────────▶   GND
GPIO 7    ───10kΩ───▶       SCL
                    │
                   10kΩ
                    │
GPIO 6    ───10kΩ───┼──▶    SDA
                    │
                   10kΩ
                    │
GND       ◀──────────┘

注：I2C 总线需要上拉电阻 (10kΩ)
```

### 3.2 按键电路

```
ESP32-C6
────────
GPIO 4    ───10kΩ───▶ 3.3V
            │
           按键
            │
GND       ◀─┘

注：按键按下时 GPIO 4 被拉低到 GND
    使用内部下拉电阻或外部上拉电阻
```

### 3.3 LED 电路

```
ESP32-C6
────────
GPIO 3    ───220Ω───▶ LED(+)
                      LED(-) ───▶ GND

注：220Ω限流电阻，LED 电流约 10mA
```

### 3.4 USB Type-C 电路

```
USB Type-C                ESP32-C6
───────────               ────────
VBUS      ────┬───────▶  5V_IN
              │
             10uF
              │
             GND

D+        ─────────────▶  D+ (GPIO 19)
D-        ─────────────▶  D- (GPIO 18)
GND       ─────────────▶  GND
CC1       ───5.1kΩ───▶  GND (下拉电阻)
CC2       ───5.1kΩ───▶  GND (下拉电阻)
```

### 3.5 电源管理电路

```
USB 5V ────▶ AP2112K-3.3 ────▶ 3.3V_系统
              │
             10uF
              │
             GND

电池 3.7V ────▶ AP2112K-3.3 ────▶ 3.3V_系统
              │
             10uF
              │
             GND

注：USB 供电优先，电池作为备用
```

## 四、PCB 设计规格

### 4.1 尺寸要求

```
PCB 尺寸：35mm × 25mm
层数：2 层
厚度：1.6mm
板材：FR-4
```

### 4.2 布局要点

```
┌──────────────────────────────────────┐
│  USB-C    │     ESP32-C6            │
│  (底部)   │    (21.6×18.2mm)        │
│           │                         │
│  ┌─────┐  │    ┌─────────────┐      │
│  │电池 │  │    │   MPU6050   │      │
│  │300mAh│  │    │  (4×4mm)    │      │
│  └─────┘  │    └─────────────┘      │
│           │                         │
│  [按键]          [LED]              │
└──────────────────────────────────────┘
        35mm
```

### 4.3 关键布局规则

1. **MPU6050 位置**: 靠近 PCB 中心，远离电源噪声
2. **USB 差分对**: 等长布线，阻抗 90Ω
3. **RF 天线**: 保持净空区，远离金属
4. **电源路径**: 短而宽，减少压降
5. **I2C 走线**: 尽量短，避免平行长距离走线
