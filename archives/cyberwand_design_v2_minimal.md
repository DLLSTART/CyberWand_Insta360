# CyberWand 最小化设计 (v2 - 精简版)

## 项目名称：insta360 CyberWand Lite

**设计目标**：
- 移除UI交互需求
- 简化为两个模式切换
- 最小化物理尺寸
- 保留核心功能

---

## 一、核心需求对比

| 功能 | v1原版 | v2精简版 | 说明 |
|------|--------|----------|------|
| 显示屏 | OLED 1.3寸 | ❌ 移除 | 无UI交互 |
| 按键 | 触摸按键 | ✅ 单物理按键 | 模式切换 |
| LED | 多个LED | ✅ 1个LED | 灯语指示 |
| IMU | 6轴传感器 | ✅ 保留 | 手势识别 |
| 蓝牙 | 5.0 | ✅ 5.4 | 连接设备 |
| 电池 | 300mAh | ✅ 300mAh | 供电 |
| USB | 充电 | ✅ USB-C | 充电 |
| SD卡 | ❌ | ❌ 移除 | 无存储需求 |

## 三、精简后的工作流程

### 模式切换

```
物理按键
   ↓
单击一次：
   ┌─────────────────┐
   │ 模式1：控制模式  │ ←→ 识别手势 → 控制相机
   └─────────────────┘
   
   长按2秒：
   ┌─────────────────┐
   │ 模式2：录制模式  │ ←→ 录制数据 → 蓝牙发送
   └─────────────────┘
```

### 蓝牙协议

```
录制模式：
  - 记录手势序列
  - 压缩数据
  - 蓝牙5.4发送到对端

控制模式：
  - 识别手势
  - 解析手势类型
  - 发送对应蓝牙指令
```

### LED灯语

| 模式 | 灯光 | 说明 |
|------|------|------|
| 空闲 | 闪烁 | 等待连接 |
| 控制 | 常亮 | 手势识别中 |
| 录制 | 快闪 | 录制数据 |
| 蓝牙 | 慢闪 | 正在传输 |

## 四、最小化物理设计

### 3D模型估算

```
尺寸：35mm × 25mm × 8mm
体积：7000 mm³ (7cm³)
重量：约 8-10g

参考：
  • 信用卡大小 (~85×54mm) - 小很多
  • 硬币大小 (~25mm) - 略大
  • 拇指指甲大小 - 相近
```

### 3D打印外壳建议

```
外壳尺寸：36mm × 26mm × 9mm (留公差)
外壳形状：流线型手掌贴合设计
外壳材料：TPU软胶 + PC硬壳

按键位置：
  - 顶部：单物理按键 (直径6mm)
  - 底部：USB-C接口 (Type-C)
  
LED位置：
  - 侧面：单LED (可见窗口)
```

## 五、软件设计简述

### 核心功能

1. **手势识别** (IMU)
   - 识别挥手、握拳、旋转
   - 映射到相机控制指令

2. **录制模式**
   - 记录手势序列
   - 压缩存储
   - 蓝牙传输

3. **蓝牙通信**
   - 广播服务
   - 点对点连接
   - 指令发送/接收

### 简化后的代码结构

```
src/
├── main.c              # 主程序
├── gesture.c           # 手势识别 (IMU)
├── bluetooth.c         # 蓝牙通信
├── mode_switch.c       # 模式切换 (按键)
└── led.c               # LED灯语
```
