# OpenClaw Browser Relay 扩展安装指南

## 📦 文件结构

```
browser-extension/
├── manifest.json      # 扩展配置
├── background.js      # 后台脚本
├── popup.html         # 弹出页面
├── popup.js           # 弹出页面脚本
├── content.js         # 内容脚本
└── icons/             # 图标文件夹（可选）
    ├── icon16.png
    ├── icon48.png
    └── icon128.png
```

## 🔧 安装步骤

### 步骤 1：准备图标（可选）

扩展可以无图标运行，但建议创建简单图标：

**方式 A：使用在线工具生成**
1. 访问 https://favicon.io
2. 创建文字图标（如 "OC"）
3. 下载 16x16、48x48、128x128 三种尺寸
4. 放入 `icons/` 文件夹

**方式 B：使用默认图标**
如果没有图标，扩展也能正常运行，只是浏览器显示默认图标。

### 步骤 2：加载扩展到 Chrome

1. **打开扩展管理页面**
   - Chrome 地址栏输入：`chrome://extensions/`
   - 或：菜单 → 更多工具 → 扩展程序

2. **开启开发者模式**
   - 点击右上角的 **「开发者模式」** 开关
   - 确保开关变为蓝色（开启状态）

3. **加载扩展**
   - 点击 **「加载已解压的扩展程序」** 按钮
   - 选择文件夹：`D:\workspace\CyberWand_Insta360\host_program\feishu_bot\browser-extension`
   - 确认选择

4. **验证安装**
   - 扩展列表中应出现 "OpenClaw Browser Relay"
   - 状态显示为「已启用」

### 步骤 3：使用扩展

1. **打开飞书开发者平台**
   - 访问：https://open.feishu.cn/app
   - 确保已登录飞书账号

2. **激活扩展**
   - 点击浏览器右上角的 OpenClaw 扩展图标
   - 点击 **「连接网关」**（如果 OpenClaw 网关已运行）
   - 点击 **「激活当前标签」**

3. **验证激活**
   - 扩展图标徽章应显示绿色 **"ON"**
   - 此时 OpenClaw 可以控制该标签页

## ⚠️ 常见问题

### 问题 1：扩展图标不显示
**解决**：
- 检查扩展是否已启用
- 重启 Chrome 浏览器
- 重新加载扩展

### 问题 2：无法连接网关
**解决**：
- 确保 OpenClaw 网关正在运行
- 检查命令行：`openclaw gateway status`
- 如需启动：`openclaw gateway start`

### 问题 3：徽章不变绿
**解决**：
- 确保在飞书页面上点击「激活当前标签」
- 刷新页面后重新激活
- 检查扩展权限是否已授予
