### 3.2 工作模式实现

#### 录制模式
```c
MODE_RECORD:
├── 单击 → 切换到控制模式
├── 长按 → 持续发送 IMU 数据到 USB
└── 正常 → 发送 IMU 数据到 USB
```

#### 控制模式
```c
MODE_CONTROL:
├── 单击 → 切换到录制模式
├── 长按 → 持续姿态检测 + 蓝牙发送
└── 正常 → 姿态变化时蓝牙发送
```

### 3.3 姿态识别模型

| 姿态 | 检测条件 | 阈值 |
|------|----------|------|
| **空闲** | 无动作 | - |
| **握拳** | Z 轴加速度 > 1500mg | 1500 |
| **挥手** | X 轴加速度 > 800mg + Y 轴陀螺仪 > 500mdps | 800/500 |
| **左旋转** | Z 轴陀螺仪 > 500mdps | 500 |
| **右旋转** | Z 轴陀螺仪 < -500mdps | -500 |
| **上倾斜** | X 轴加速度 > 300mg | 300 |
| **下倾斜** | X 轴加速度 < -300mg | -300 |
