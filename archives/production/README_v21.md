## 四、组装指南

### 4.1 工具准备

```
必备工具：
├── 电烙铁（恒温，尖头）
├── 焊锡丝（0.5mm，含松香）
├── 助焊剂
├── 剥线钳
├── 螺丝刀（M2 十字）
├── 镊子（弯头）
└── 万用表

辅助工具：
├── 热风枪（热缩管）
├── 胶水（AB 胶/UV 胶）
├── 电工胶带
└── 防静电手环
```

### 4.2 PCB 组装（手柄内）

#### 步骤 1：焊接主控板

```
ESP32-S3-WROOM-1 焊接：
1. 清洁 PCB 焊盘（异丙醇）
2. 涂抹助焊剂
3. 对准 ESP32-S3 模块（注意方向）
4. 先焊接对角 2 个引脚固定
5. 依次焊接所有引脚
6. 检查短路（万用表蜂鸣档）
```

#### 步骤 2：焊接 MPU6050

```
MPU6050 I2C 连接：
├── VCC → 3.3V
├── GND → GND
├── SCL → GPIO10 (I2C_SCL)
└── SDA → GPIO11 (I2C_SDA)

焊接顺序：
1. 焊接 4 个引脚
2. 检查 I2C 通信（万用表）
```

#### 步骤 3：焊接 USB-C 母座

```
USB-C 16Pin 焊接：
├── VBUS (A4/B9) → 5V
├── GND (A1/A12/B1/B12) → GND
├── D+ (A6/B6) → GPIO19 (USB_D+)
├── D- (A7/B7) → GPIO18 (USB_D-)
└── CC1/CC2 → 5.1kΩ下拉到 GND

注意：
- USB-C 母座引脚密集，使用 0.3mm 焊锡丝
- 先焊接固定脚，再焊接信号脚
- 检查相邻引脚是否短路
```

#### 步骤 4：焊接按键

```
3 个轻触开关焊接：
├── KEY1 (Mode) → GPIO0 + GND
├── KEY2 (Select) → GPIO3 + GND
└── KEY3 (Play) → GPIO8 + GND

安装位置：
- 手柄侧面开孔Φ6mm
- 按键帽用 AB 胶固定
```

#### 步骤 5：焊接 LED 驱动

```
WS2812B 连接：
├── VDD → 5V（从电池取电）
├── GND → GND
└── DIN → GPIO7

注意：
- LED 安装在杖尖，需要长导线（约 350mm）
- 使用 30AWG 硅胶线（柔软）
- 导线穿入杖身中空部分
```

#### 步骤 6：焊接电池连接

```
电池管理电路：
├── 电池+ → TP4056 BAT
├── 电池- → GND
├── TP4056 OUT → 3.3V LDO 输入
└── LDO 输出 → 3.3V 网络

充电指示 LED：
├── CHRG → 红色 LED（充电中）
└── STDBY → 绿色 LED（充满）
```

### 4.3 外壳组装

#### 步骤 1：手柄组装

```
1. 将 PCB 卷成圆筒状（Φ24mm）
2. 放入手柄外壳（Φ25mm 内径）
3. 用 3M 双面胶固定 PCB
4. 安装按键帽（AB 胶）
5. 盖上手柄底盖（螺纹旋紧）
```

#### 步骤 2：杖身组装

```
杖身分 4 段打印，螺纹连接：
1. 段 1 连接手柄（M10 内螺纹）
2. 段 2-3 螺纹连接（M8）
3. 段 4 连接杖尖（M6）

导线穿引：
1. 先穿 LED 导线（350mm）
2. 再穿电池线（到手柄）
3. 用热缩管保护导线
```

#### 步骤 3：杖尖组装

```
1. 焊接 WS2812B 到导线
2. 放入杖尖外壳
3. 用 UV 胶固定（透明，透光）
4. 等待 UV 固化（365nm，2 分钟）
```

#### 步骤 4：最终组装

```
1. 手柄 + 杖身螺纹旋紧
2. 杖身分段螺纹旋紧
3. 杖尖旋紧
4. 测试所有功能
5. 螺丝孔点 AB 胶固定（防松）
```

### 4.4 固件烧录

```
1. 按住 KEY1 (GPIO0) 接地
2. 连接 USB-C 到电脑
3. 电脑识别为 USB 串口
4. 使用 esptool 烧录固件：
   esptool.py --chip esp32s3 write_flash 0x0 firmware.bin
5. 复位，运行固件
```

## 五、功能测试

### 5.1 测试清单

| 测试项 | 方法 | 预期结果 |
|--------|------|---------|
| **USB 充电** | 连接 USB-C，测电压 | 红灯亮，电池电压上升 |
| **USB 通信** | 连接电脑，串口调试 | 识别为串口设备 |
| **按键测试** | 按下 3 个按键 | 对应 GPIO 电平变化 |
| **MPU6050** | I2C 扫描 | 地址 0x68 响应 |
| **LED 测试** | 发送颜色指令 | WS2812B 变色 |
| **姿态识别** | 挥动魔杖 | 识别握拳/挥手/旋转 |

### 5.2 故障排查

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| **无法充电** | USB-C 虚焊 | 重新焊接 VBUS/GND |
| **无法烧录** | GPIO0 未接地 | 按住 KEY1 再连接 USB |
| **MPU6050 无响应** | I2C 接线错误 | 检查 SCL/SDA 接线 |
| **LED 不亮** | 5V 供电缺失 | 检查电池连接 |
| **按键无反应** | 按键虚焊 | 重新焊接按键 |

## 八、注意事项

### 8.1 安全警告

⚠️ **锂电池安全**：
- 使用带保护板的锂电池
- 充电时不要无人看管
- 避免短路、过充、刺破

⚠️ **焊接安全**：
- 使用恒温烙铁（≤350°C）
- 保持通风（焊锡烟雾）
- 佩戴防静电手环

### 8.2 打印质量

- **层厚 0.2mm** - 平衡速度与质量
- **填充 20%** - 足够强度
- **支撑必要** - 悬垂部分需要支撑
- **后处理** - 去除支撑，打磨接缝
